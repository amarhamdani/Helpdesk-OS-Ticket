MRMIK 2.1 & 2.2 • PERTAHANAN BERLAPIS Domain: helpdesk.rsmakiyah.com

Pusat Pertahanan Kerentanan Aplikasi & Hardening Server

Monitoring dan mitigasi defensif terhadap kerentanan SQL Injection (SQLi), Cross-Site Scripting (XSS), penyusupan PHP Web Shell / Backdoor, CSRF, serta salah konfigurasi hak akses direktori cPanel.

TERMITIGASI (PDO + WAF)

1. SQL Injection (SQLi)

Seluruh kueri database SIMRS wajib menggunakan Prepared Statements (PDO / MySQLi Bind Parameter) serta validasi tipe data ketat dan filter WAF pada input form.

TERPROTEKSI (DOM ESCAPE)

2. Cross-Site Scripting (XSS)

Sanitisasi otomatis seluruh input dan output HTML (escapeHTML / htmlspecialchars) untuk mencegah eksekusi skrip berbahaya di browser staf medis.

TERBLOKIR (UPLOAD & PHP)

3. PHP Web Shell & RCE

Penonaktifan fungsi eksekusi sistem pada php.ini (exec, shell_exec, system, passthru) dan pemblokiran eksekusi PHP di folder /uploads.

TERPANTAU (FIM & AV)

4. Backdoor & File Integrity

Pemindaian rutin Imunify360 / ClamAV di cPanel, pengecekan hash integritas file inti, serta pemeriksaan berkala daftar cron jobs dan akun FTP/SSH.

AKTIF (TOKEN & SAMESITE)

5. CSRF & Session Hijacking

Penerapan token anti-CSRF pada setiap perubahan data, atribut cookie HttpOnly; Secure; SameSite=Strict, serta auto-logout sesi idle.

HARDENED (CHMOD 644/755)

6. Directory Traversal & Config

Penonaktifan Directory Listing (Options -Indexes), proteksi file .env / config.php via .htaccess, dan izin file standar 644/755.

SOP & PERTOLONGAN PERTAMA

SOP MRMIK 2.1 EP a & b

Lupa Password / User ID SIMRS Terkunci

  1. Dilarang keras meminjam akun/password rekan kerja (melanggar kerahasiaan data pasien MRMIK 2.1).
  2. Pastikan tombol CapsLock tidak aktif saat mengetik password.
  3. Buat tiket kategori Manajemen Akun & Hak Akses dengan mencantumkan NIP/NIK dan Unit Kerja untuk verifikasi otorisasi reset password oleh Staf IT.
SOP MRMIK 13.1 (DOWNTIME)

Prosedur Darurat Saat SIMRS / Jaringan Mati Total

  1. Hubungi Ext. IT (101) atau buat tiket Kritis jika jaringan lokal masih dapat diakses.
  2. Jika gangguan melebihi 30 menit (batas toleransi SPO), Kepala Unit mengaktifkan Formulir Rekam Medis & Resep Manual Darurat yang tersedia di map kontingensi unit.
  3. Setelah sistem pulih, staf unit wajib melakukan input susulan (back-entry) ke e-RM maksimal 1x24 jam.
KEAMANAN SIBER (MRMIK 2.1)

Penanganan Aktivitas Mencurigakan, Phishing & Malware

  1. Jangan membuka lampiran email/tautan tidak dikenal atau mencolokkan flashdisk pribadi ke PC SIMRS unit.
  2. Jika muncul peringatan blokir keamanan, halaman error aneh, atau file asing di PC pelayanan, segera cabut kabel LAN sementara dan lapor ke Unit IT.
  3. Selalu tekan Log Out atau Win + L setiap meninggalkan meja komputer.
HARDWARE & PERIPHERAL

Printer Label Gelang / SEP / Resep Tidak Mencetak

  1. Periksa lampu indikator printer (jika berkedip merah/oranye, pastikan gulungan label/kertas & ribbon terpasang rapat).
  2. Matikan printer selama 10 detik lalu nyalakan kembali untuk kalibrasi kertas otomatis.
  3. Pastikan nama printer yang dipilih pada dialog cetak browser sesuai dengan unit Anda dan tidak berstatus Offline.
